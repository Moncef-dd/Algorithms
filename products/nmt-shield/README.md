# NMT Shield

Financial fraud detection through risk scoring. [catalogue, slides 3-4]

## Summary

Analyses bank transactions and identifies suspicious operations using an advanced risk-scoring system.

## Target user

Banks and financial institutions; fraud and risk teams handling alerts. [catalogue + inferred]

## Key features

1. **Real-time scoring API.** Scores transactions in real time, ready to integrate into the bank's internal
   systems and applications.
2. **Centralised dashboard.** Single view to follow, manage and analyse the alerts the detection system raises.
3. **Alert management platform.** Full control of detection operations and structured handling of flagged
   transactions.

## Key benefits (catalogue wording, as claims)

| Benefit | Claim |
| --- | --- |
| Détection en temps réel | Advanced AI algorithms to identify fraud and suspicious behaviour |
| Moins de pertes | "Réduction significative" of fraud and false positives through intelligent scoring |
