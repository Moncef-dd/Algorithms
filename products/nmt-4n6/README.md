# NMT 4n6

Digital investigation and centralised exploitation of evidence. [catalogue, slides 11-12]

"4n6" is a common shorthand for "forensics" (four, n, six); the catalogue does not spell this out. [inferred]

## Summary

A digital forensics platform for collecting, analysing and exploiting digital evidence in a single, intuitive
environment, for investigation and security contexts. It centralises the key stages of evidence handling.

## Target user

Digital investigation teams and security teams. [catalogue, slide 11]

## Key features

1. **Digital evidence collection.** Gathers evidence in one environment.
2. **Centralised analysis and exploitation.** Analyse and exploit evidence from the same platform.
3. **Unified evidence processing.** Key processing steps combined in a single workflow.
4. **Clear, intuitive interface.** Designed for team operational efficiency.

## Key benefits (catalogue wording, as claims)

| Benefit | Claim |
| --- | --- |
| Efficacité opérationnelle | Intuitive interface suited to investigation teams |
| Preuves centralisées | Collection and processing in a single environment |
| Analyse accélérée | Tools designed to save time in investigations |

"Projet phare" and "Produit finalisé, prêt à déployer" (finished product, ready to deploy). [catalogue, slide 11]
