# TeamPilot

Sovereign, self-hosted conversational AI, running local or cloud models. [catalogue, slides 9-10]

## Summary

A conversational AI platform offering one interface to interact with local or cloud AI models in a secure,
self-hosted environment.

## Target user

Enterprises, banks and administrations; the catalogue positions it for all teams and internal uses. [catalogue]

## Key features

1. **Data sovereignty.** "Zero trust" environment centred on confidentiality.
2. **Local or cloud models.** Unified interface; models run locally or in the cloud.
3. **Agents & automation.** Intelligent agents and business-process automation.
4. **RAG & MCP integration.** Retrieval-augmented generation and Model Context Protocol for contextual AI.
5. **Enterprise customisation.** Adapted to each organisation's needs and information system.

## Key benefits (catalogue wording, as claims)

| Benefit | Claim |
| --- | --- |
| Sécurité maximale | Data hosted locally or in a sovereign cloud, full control, guaranteed compliance |
| Productivité accrue | AI agents and automation: fewer repetitive tasks |
| Collaboration intelligente | Unified conversational interface for all teams and internal uses |
| Intégration flexible | Connectors and APIs to integrate existing tools, data and systems |
| Solution évolutive | Modular, scalable platform |
